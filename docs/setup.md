# セットアップ手順

clone した直後から、OBS に表示が出るまでの手順。Windows 向け。

所要時間は 15〜20 分程度。**わんコメと OBS の導入を含む**ので、すでに両方使っているなら手順3から始めればよい。

## 実行環境

| | 必要なもの | 備考 |
|---|---|---|
| OS | Windows 10 / 11 | `install.ps1` が PowerShell スクリプトのため。Mac には導入手順が無い |
| わんコメ（OneComme） | 9.1.6 で確認 | 無料版で動く。PRO は不要 |
| OBS Studio | 32.1.2 で確認 | 内蔵ブラウザ（CEF）127 で表示を確認済み |
| ネット接続 | 要 | YouTube へのログインと、表示画面の Web フォント取得に使う |
| ポート | 11180 を使用 | わんコメが使う。他のアプリと衝突しないこと |

**Node.js は使うだけなら要らない。** `npm test` や `npm run dev`（わんコメ無しでの開発）を行うときだけ必要（v22.11.0 で確認）。

## 1. わんコメを入れて YouTube と繋ぐ

1. [onecomme.com/download](https://onecomme.com/download) で **Windows 64bit** を選び、インストーラを実行する。
2. 起動すると配信サイトの選択が出る。**YouTube** を選ぶ。
3. 「未ログイン」と表示されていたら「ウェブブラウザで開く」からログインする。ログインしておくとメンバー限定配信のコメントも取れる。
4. 右上の × で閉じる。あとから変えるときは **設定 → サイト別**。

配信枠は、次の形式の URL を登録できる。自分の配信を立てる前に試すなら、他人のライブ配信の URL でも動作を確認できる。

```
https://youtube.com/watch?v=<ID>
https://www.youtube.com/watch?v=<ID>
https://www.youtube.com/live/<ID>
```

## 2. ファイルをわんコメへコピーする

**わんコメを一度起動したあとで**実行すること（`%APPDATA%\onecomme` が作られている必要がある）。

clone したフォルダで PowerShell を開いて：

```powershell
.\install.ps1
```

コピー先はこの2つ。

```
%APPDATA%\onecomme\plugins\fc-counter\
%APPDATA%\onecomme\templates\custom\fc-counter\
```

実行がブロックされる場合は次で回避する。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

## 3. プラグインを有効にする

1. わんコメの**右上のメニュー**から**プラグインウィンドウ**を開く。
2. 「**再読み込み**」を押す。
3. 一覧に **fc-counter** が出るので、**チェックボックスで有効化**する。

プラグインを書き換えたときも、この「再読み込み」を押さないと反映されない。

## 4. 疎通を確かめる

ブラウザで次を開く。

```
http://localhost:11180/api/plugins/fc-counter.local
```

**正常**なら、`{"code":200,"response":"{\"schema\":1,...`  という JSON が返る。

**こう返る場合**はプラグインが有効になっていない。手順3へ戻る。

```json
{"statusCode":400,"error":"Bad Request","message":"Notfound plugin (fc-counter.local)"}
```

## 5. OBS に表示画面を登録する

配信に映る側。

1. ソース → **＋** → **ブラウザ**
2. URL: `http://localhost:11180/templates/custom/fc-counter/index.html`
3. 幅 `1920` / 高さ `1080`

背景は透過しているので、他のソースの上に重ねられる。

## 6. OBS に操作画面を登録する

**配信には映らない**、自分用の操作パネル。OBS のウィンドウ内にドッキングする。

1. OBS のメニューバーの **「ドック(D)」** → **「カスタムブラウザドック(D)」**
2. **ドック名**: `fc-counter`
3. **URL**: `http://localhost:11180/templates/custom/fc-counter/controller.html`
4. 「適用」または「閉じる」を押すとパネルが現れる。ドラッグで好きな位置へ動かせる。独立したウィンドウに切り離すこともできる。

## 7. 動作を確かめる

### 操作画面から

操作画面の下部にあるテスト用のボタン（**コメント / コメント×5 / 初見コメント / スパチャ / メンバー加入**）を押す。表示画面の数が 0.3 秒ほどで追従すれば成功。

### わんコメのコメントテスターから（こちらが本番に近い）

わんコメの**コメントテスター**（ダミーコメンター）は、**本物と同じデータ形式**でイベントを流せる。配信も課金も要らない。

- サービスで **YouTube** を選ぶ
- 「ギフト/スパチャ」を**あり**にすると、ギフトタイプと**金額**を指定して送れる
- 繰り返し間隔（ms）を指定すると連投できる

これでコメント数とスパチャ金額が増えれば、本番でも動く。

**注意**: コメントテスターでは `meta`（同時接続数・高評価数）は流れない。この2つを確かめるには、実際に配信枠を接続する必要がある（[handoff.md](handoff.md) 参照。ここは未検証のまま残っている箇所）。

## 操作画面の使い方

| 場所 | できること |
|---|---|
| ＋ 項目を追加 | 数える対象を追加する。最大10個 |
| ⚙ | 項目ごとの設定（名前・目標・色・連投制限・キーワード・1人1回など） |
| +1 / +10 / +100 / −1 | 手動で補正する |
| 0に戻す | その項目だけ 0 に戻す |
| ↑ ↓ | 並び順を変える |
| 新しい配信を始める | すべての数を 0 に戻す。**配信ごとに押す** |
| 位置 | 表示画面内の配置をプリセットから選ぶ |
| 大きさ | 40%〜200% |
| 目標達成で画面全体の演出を出す | 達成時の帯と紙吹雪の有無 |

## 詰まったときの切り分け

| 症状 | 見るところ |
|---|---|
| プラグイン一覧に出てこない | `%APPDATA%\onecomme\plugins\fc-counter\plugin.js` が存在するか。わんコメを起動する前に `install.ps1` を実行していないか |
| 手順4の JSON が返らない | プラグインが有効になっているか。わんコメが起動しているか |
| OBS が真っ白 | URL が合っているか。わんコメが起動しているか。ソースを右クリック →「再読み込み」 |
| 表示は出るが数が増えない | **まずここを疑う。** `%APPDATA%\onecomme\logs\plugin.log` を見る。プラグイン内の `console.log()` がここへ出るので、`subscribe` の先頭で `JSON.stringify(args)` を吐かせると届いた中身が分かる（仕込んだら手順3の「再読み込み」が要る） |
| 同接・高評価だけ 0 のまま | 配信枠が接続されているか。未検証の箇所なので [handoff.md](handoff.md) の「次にやること」を参照 |

## 開発するとき

わんコメ無しでテンプレートとプラグインを動かせる。

```
npm run dev   # http://localhost:11180 で起動し、偽のコメントを自動で流す
npm test      # 集計ロジックのテスト
```

- **わんコメと同時に起動できない。** どちらもポート 11180 を使う
- 表示画面をブラウザで見るときは URL の末尾に `?bg=1` を付けると背景が付く
- 偽データで通したテストを根拠にしないこと。理由は [handoff.md](handoff.md) に書いてある
